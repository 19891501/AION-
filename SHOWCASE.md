# AION — projet wow

## Decision Theater

Interface immersive qui montre **pourquoi** AION refuse d'agir quand la preuve manque.

### Accès

| Mode | URL |
|------|-----|
| Fichier local | `web/static/theater.html` |
| GitHub | repo **AION-** → `web/static/theater.html` |
| Render | https://aion-3.onrender.com/static/theater.html |

### Scénarios one-click

- Virement 10 000 € → VERIFY → CONFLICT → **HUMAIN**
- Suppression production → VERIFY → bloqué
- Prémisse fausse → CLARIFY
- Hors périmètre → REFUSE
- Question simple → ANSWER / AUTORISÉ

### Message

Agent classique : intention → outil → **act**  
AION : intention → preuve → **autoriser ou non**

> La preuve décide, pas l'intention.
